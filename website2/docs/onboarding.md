# Onboarding & Development Steps

Welcome to the Email Pilots website repository. This guide will help you get set up locally and understand how to run and build the project.

## Prerequisites

- Node.js (v18 or higher recommended)
- npm (or your preferred package manager like yarn, pnpm, or bun)

## Installation Steps

1. Clone the repository and navigate to the `website` directory.
2. Install the required dependencies:
   ```bash
   npm install
   ```

## Development Procedures

To start the local development server with Hot Module Replacement (HMR):
```bash
npm run dev
```
The server will typically start on `http://localhost:5173/`. Open this URL in your browser to view the landing page.

## Available Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Type-checks the TypeScript code and bundles the project using Vite for production.
- `npm run lint`: Runs ESLint across the project to catch syntax and stylistic errors.
- `npm run preview`: Bootstraps a local server to preview the production build generated by `npm run build`.

## Making Changes

- **Landing Page Content:** The majority of the textual content, structure, and 3D scenes are currently located in `src/App.tsx`.
- **Styling:** Edit `src/index.css` for global styles or Tailwind variables. Most elements are styled using inline Tailwind classes.
- **UI Components:** Add or modify components in `src/components/ui/` if you are implementing new sections or features.

### Best Practices
- When editing the 3D scene (`AviationScene`), ensure you don't block the main thread. Keep geometries optimized.
- Use `motion` and `GSAP` judiciously to maintain the current 60fps smooth scrolling experience powered by `Lenis`.
